# Demirtaş Yönetim — Windows İndirmleri

Bu depo yalnızca Demirtaş Yönetim Windows kurulum dosyalarının resmi dağıtımı içindir. Uygulamanın kaynak kodu veya müşteri verileri burada bulunmaz.

## Kurulum ve güncelleme

Güncel Windows kurulum dosyalarını bu deponun [Releases](../../releases) bölümünden indirebilirsiniz. Kurulumdan önce uygulamanın açık pencerelerini kapatın ve yerel verilerinizi yedekleyin. Kurulum paketini mümkünse yayımlanan SHA-256 değeriyle doğrulayın.

Windows SmartScreen bilinmeyen yayımcı uyarısı gösterebilir; bu sürümlerde henüz dijital kod imzası bulunmamaktadır.
